# jacek4yang profile repository assets

`mono.svg` — minimalist wordmark glyph used in the profile README heading.
Monochrome (`currentColor`-style fixed dark stroke) so it renders on both
light and dark GitHub themes without custom theming. Rendered inline with a
fixed `width="28"`; GitHub sanitizes inline styles, so keep the SVG
attribute-only.

Design intent: a rounded-rect frame containing a code-bracket pair with a
single point between them — reads as "systems / protocol" at 28px, stays
quiet next to the heading text.
